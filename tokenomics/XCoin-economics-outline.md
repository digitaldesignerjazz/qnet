# XCoin / QCoin Economics Outline

**Status**: Initial draft / work in progress

## Overview
XCoin (and its QCoin variant) forms the native value and incentive layer for the QNET protocol and the broader Esslinger & Co. ecosystem.

## Primary Goals
- Incentivize participation in mesh networking (node operation, bandwidth, storage)
- Enable sustainable economics for AI agent swarms and coordination
- Support rune-based assets and custom logic (Wizard Q)
- Facilitate arbitrage and value transfer across mesh and blockchain layers

## Key Economic Mechanisms (Planned)

### Token Supply & Distribution
- Initial allocation model
- Staking and locking mechanisms for node operators and agents
- Inflation/deflation parameters aligned with network growth

### Incentive Models
- Rewards for mesh node uptime, peering quality, and data contribution
- Agent swarm participation incentives
- Governance or coordination rewards

### Rune Economics (Wizard Q)
- Design of rune assets with utility in mesh coordination or AI tasks
- Minting, burning, and transfer rules
- Integration with protocol-level logic

### Arbitrage & Cross-Layer Value
- Mechanisms for value to flow between mesh services and on-chain tokens
- Price discovery and stability considerations
- Opportunities arising from mesh-blockchain-AI convergence

## Integration with Other Layers
- **Mesh (Xanadu + xmesh)**: Tokens reward real-world network contributions
- **AI Agents (Nexus)**: On-chain payments and incentives for swarm tasks
- **Overall Ecosystem**: Sustainable flywheel between usage, contribution, and value

## Open Questions
- Optimal staking and slashing models for decentralized mesh
- Balance between on-chain incentives and off-chain mesh realities
- Long-term monetary policy aligned with self-improving systems vision

## Next Steps
- Detailed tokenomic model and simulations
- Incentive mechanism design documents
- Economic security analysis
